## 3. 決定事項

- フル設計として、アーキテクチャ、データフロー、Swift型、Firestore、Storage、Security Rulesを作成する。🔵
- TypeScript型定義やSQLスキーマは作成せず、Swift/Firebase向け文書に置き換える。🔵
- 独自APIサーバーとCloud Functionsは初期前提にしない。🔵
- Firestoreは年/月単位で分割し、公開用結果と個別入力を分離する。🔵
- Storageは `mediaAssets` を中心に参照管理する。🔵
- メディアは軽量化して保存し、位置情報は除外する。🔵
- 端末またはiCloud写真ライブラリ上の元写真・元動画・元Live Photosは変更・削除しない。削除対象はFirebase Cloud Storage上の派生ファイルに限定する。🔵
