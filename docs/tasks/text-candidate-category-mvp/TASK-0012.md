- **設計文書**: [screen-structure.md](../../design/text-candidate-category-mvp/screen-structure.md)

## タスク概要

部門全体リセットの確認UIと、Firestore保存失敗・リセット失敗・権限エラー時の共通表示方針を実装する。

## 依存タスク

- **前提タスク**: [TASK-0005](TASK-0005.md), [TASK-0011](TASK-0011.md)
- **後続タスク**: [TASK-0013](TASK-0013.md)

## 完了条件

- [ ] リセット前に対象部門全体のリセットであることを確認する。
- [ ] リセット後、候補と部門設定は残り、確定前状態へ戻る。
- [ ] リセット失敗時に削除済みに見せず、再取得または再試行できる。
- [ ] 保存失敗時に入力中の内容を可能な限り保持する。

---

## 実装詳細

### 1. リセット確認UIを実装する 🔵

**信頼性**: 🔵 *UI-010, REQ-105 より*

`confirmationDialog` または `alert` で、候補と設定は残り、2人分の入力と結果が削除または無効化されることを示す。

**実装ファイル**: `SelectBestPhoto/Features/TextCategories/Views/`

### 2. リセット実行後の遷移を実装する 🔵

**信頼性**: 🔵 *REQ-014, REQ-106 より*

成功後は候補・設定編集へ戻し、再確定と再入力ができる状態にする。

### 3. 共通エラー表示を整える 🔵

**信頼性**: 🔵 *EDGE-001, EDGE-002, screen-structure.md 共通エラーより*

内部エラー詳細を出さず、ユーザーが再試行・再取得など次に取る行動を理解できる文言にする。
