## タスク概要

候補を手入力で追加・編集・削除し、関連画像の将来拡張用プレースホルダーを表示し、候補・設定を確定できる候補管理画面を実装する。

- **前提タスク**: [TASK-0004](TASK-0004.md), [TASK-0008](TASK-0008.md)
- **後続タスク**: [TASK-0010](TASK-0010.md)

## 完了条件

- [x] 候補を手入力で追加できる。
- [x] 候補名を編集・削除できる。
- [x] 同名候補を別候補として扱える。
- [x] 各候補に画像プレースホルダーが表示される。
- [x] 候補不足時は確定できず、確定後は候補・設定変更が無効になる。

## 実装詳細

### 1. 候補一覧と入力欄を実装する 🔵

**信頼性**: 🔵 *UI-006, REQ-003〜REQ-005 より*

最大100件を想定した一覧と、画面下部の候補追加入力欄を実装する。

**実装ファイル**: `SelectBestPhoto/Features/TextCategories/Views/TextCandidateManagementView.swift`

### 2. 画像プレースホルダーを実装する 🔵

**信頼性**: 🔵 *REQ-017, REQ-407, REQ-408 より*

画像枠またはプレースホルダーだけを表示し、画像選択・保存・アップロード操作は出さない。

**実装ファイル**: `SelectBestPhoto/Features/TextCategories/Components/TextCandidateImagePlaceholder.swift`

### 3. 候補・設定確定を実装する 🔵

**信頼性**: 🔵 *REQ-019, REQ-101, REQ-109, REQ-110 より*

候補数が入力対象順位以上のときだけ確定できるようにし、確定後は編集操作を無効化する。
