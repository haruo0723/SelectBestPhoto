## タスク概要

自分だけ完了している間は相手の入力内容を表示しない待機画面を実装し、両者完了後に発表対象順位までの結果を表示する。

## 依存タスク

- **前提タスク**: [TASK-0003](TASK-0003.md), [TASK-0005](TASK-0005.md), [TASK-0010](TASK-0010.md)
- **後続タスク**: [TASK-0012](TASK-0012.md), [TASK-0013](TASK-0013.md)

## 完了条件

- [x] 待機画面では相手の入力状況だけを表示する。
- [x] 両者完了前の相手入力、相手順位、集計結果を表示しない。
- [x] 両者完了後に結果を生成または再利用して表示する。
- [x] 結果は発表対象順位まで、下位から上位へ順に表示できる。

---

## 実装詳細

### 1. 待機画面を実装する 🔵

**信頼性**: 🔵 *UI-008, REQ-103, REQ-204 より*

自分の完了状態と相手の完了状態だけを表示し、相手の選択内容を取得・表示しない。

**実装ファイル**: `SelectBestPhoto/Features/TextCategories/Views/TextCategoryWaitingView.swift`

### 2. 結果ViewModelを実装する 🔵

**信頼性**: 🔵 *REQ-011, REQ-012, REQ-015, REQ-104 より*

現世代の保存済み結果を再利用し、なければ両者完了データから生成して保存する。

**実装ファイル**: `SelectBestPhoto/Features/TextCategories/ViewModels/TextCategoryResultViewModel.swift`

### 3. 結果表示UIを実装する 🔵

**信頼性**: 🔵 *UI-009, screen-structure.md 結果画面より*

候補名、合計ポイント、各ユーザー由来ポイント、画像プレースホルダーを表示する。MVPでは高度な演出を作り込まない。

**実装ファイル**: `SelectBestPhoto/Features/TextCategories/Views/TextCategoryResultView.swift`
