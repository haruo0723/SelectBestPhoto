**実装ファイル**: `SelectBestPhoto/Models/TextCategories/`

### 3. バリデーションを実装する 🔵

**信頼性**: 🔵 *REQ-006〜REQ-008, REQ-101, REQ-102, EDGE-102, EDGE-103 より*
