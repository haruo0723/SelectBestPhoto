## 実装詳細

### 1. Repository protocolを定義する 🟡

**信頼性**: 🟡 *interfaces.swift.md のRepository境界より*

部門、候補、入力、結果、リセットの読み書き操作を protocol として定義する。UI側はこの protocol に依存させる。

**実装ファイル**: `SelectBestPhoto/Services/Firebase/`

### 2. PairContextProviderを定義する 🟡

**信頼性**: 🟡 *Firebase Anonymous Authentication + ペアコード方針からの補完*

認証済みユーザーIDと現在のペアIDを取得する境界を作る。MVP実装時にペア基盤が未完成の場合は、既存のペア文脈に合わせて差し替えられるよう protocol にする。

**実装ファイル**: `SelectBestPhoto/Services/Firebase/`

### 3. Firestoreパス生成を集約する 🔵

**信頼性**: 🔵 *firestore-schema.md のコレクション構成より*

`pairs/{pairId}/years/{year}/textCategories/{categoryId}` とサブコレクションのパス生成を1箇所に集約する。

**実装ファイル**: `SelectBestPhoto/Services/Firebase/`
