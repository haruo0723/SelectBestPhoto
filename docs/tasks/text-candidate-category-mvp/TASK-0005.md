## 実装詳細

### 1. 自分の順位入力保存を実装する 🔵

**信頼性**: 🔵 *REQ-009, REQ-010, REQ-402, REQ-403 より*

`inputs/{userId}` を自分の入力ドキュメントとして upsert する。完了時は順位数と重複選択を検証する。

**実装ファイル**: `SelectBestPhoto/Services/Firebase/`

### 2. 結果コンテキスト取得と保存を実装する 🔵

**信頼性**: 🔵 *REQ-011, REQ-012, REQ-104, REQ-205 より*

両者入力が完了している場合に、部門・候補・入力を取得し、`TextCategoryResultCalculator` の結果を保存する。

**実装ファイル**: `SelectBestPhoto/Services/Firebase/`

### 3. 部門リセットを実装する 🔵

**信頼性**: 🔵 *REQ-013, REQ-014, REQ-106 より*

入力と結果を削除または旧世代として無効化し、部門の `status` を `draft`、`generation` をインクリメント、`confirmedAt` を削除する。
