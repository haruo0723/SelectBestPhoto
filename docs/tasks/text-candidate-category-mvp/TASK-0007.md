アプリの主要導線としてフッタータブを導入し、年を切り替えられるテキスト候補型カスタム部門一覧画面を実装する。

## 完了条件

- [x] ホーム、発表、設定を含むフッタータブが表示される。
- [x] 年別部門一覧で対象年の部門、状態、自分/相手の入力状態、結果可否を確認できる。

## 実装詳細

### 1. TabViewとNavigationStackを導入する 🔵

**信頼性**: 🔵 *UI-001, UI-002 より*

既存HomeViewを活かしつつ、ホーム、発表、設定のタブを提供する。

**実装ファイル**: `SelectBestPhoto/App/`, `SelectBestPhoto/Features/Home/`

### 2. 年別部門一覧View/ViewModelを追加する 🔵

**信頼性**: 🔵 *UI-003, UI-004 より*

年切り替え、部門一覧、状態バッジ、自分/相手の完了状態、結果表示可否を表示する。

**実装ファイル**: `SelectBestPhoto/Features/TextCategories/Views/TextCategoryListView.swift`

### 3. 状態別遷移を実装する 🔵

**信頼性**: 🔵 *screen-structure.md 画面遷移条件より*

`draft`, `confirmed`, 自分完了、両者完了に応じて適切な画面へ誘導する。
