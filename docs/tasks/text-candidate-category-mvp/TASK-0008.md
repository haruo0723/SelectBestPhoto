## タスク概要

部門名、入力対象順位、発表対象順位、順位別ポイントを編集し、下書き保存できる部門作成・設定画面を実装する。

## 依存タスク

- **前提タスク**: [TASK-0001](TASK-0001.md), [TASK-0004](TASK-0004.md), [TASK-0007](TASK-0007.md)
- **後続タスク**: [TASK-0009](TASK-0009.md)

## 完了条件

- [ ] 部門名、入力対象順位、発表対象順位、順位別ポイントを編集できる。
- [ ] 不正な設定は保存できず、ユーザーに修正箇所が示される。
- [ ] 保存失敗時に入力中の値が保持される。
- [ ] 保存成功後に候補管理へ進める。

---

## 実装詳細

### 1. 設定フォームを実装する 🔵

**信頼性**: 🔵 *UI-005 より*

SwiftUIの `Form` またはスクロール可能なレイアウトで、部門名、順位数、ポイント設定を編集できるようにする。

**実装ファイル**: `SelectBestPhoto/Features/TextCategories/Views/TextCategorySettingsView.swift`

### 2. 設定ViewModelを実装する 🟡

**信頼性**: 🟡 *screen-structure.md のViewModel分割案より*

入力中の下書き、保存状態、エラー表示、Repository保存を管理する。

**実装ファイル**: `SelectBestPhoto/Features/TextCategories/ViewModels/TextCategorySettingsViewModel.swift`

### 3. バリデーション表示を実装する 🔵

**信頼性**: 🔵 *EDGE-102, EDGE-103 より*

部門名空、順位範囲外、発表順位 > 入力順位、ポイント0以下を保存前に示す。

## UI/UX要件

### 50行のポイント設定を扱える 🔵

**信頼性**: 🔵 *NFR-001, screen-structure.md より*

- ポイント設定は固定の小さい領域に押し込まず、スクロール可能にする。
- Dynamic Typeでラベルと入力値が重ならないようにする。
- 保存中、保存失敗、保存成功の状態を区別する。
