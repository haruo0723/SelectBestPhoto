## タスク概要

2人分の順位入力と部門ごとのポイント設定から、発表対象順位までの結果を生成する `TextCategoryResultCalculator` を実装する。

## 依存タスク

- **前提タスク**: [TASK-0001](TASK-0001.md)
- **後続タスク**: [TASK-0005](TASK-0005.md), [TASK-0011](TASK-0011.md)

## 完了条件

- [ ] 候補IDごとの合計ポイントを計算できる。
- [ ] 同点時に合計ポイント、最高順位、候補作成順で安定ソートできる。
- [ ] 発表対象順位までの `TextCategoryResultEntry` を生成できる。

---

## 実装詳細

### 1. 集計protocolと実装を追加する 🔵

**信頼性**: 🔵 *interfaces.swift.md の TextCategoryResultCalculating より*

`TextCategoryResultCalculating` と具象実装を追加し、Firestoreに依存しない純粋ロジックとして実装する。

**実装ファイル**: `SelectBestPhoto/Models/TextCategories/` または `SelectBestPhoto/Features/TextCategories/`

### 2. ポイント合算と内訳生成を実装する 🔵

**信頼性**: 🔵 *REQ-011, UI-009 より*

各ユーザーの選択順位からポイントを引き、候補ごとに合算し、ユーザー別の順位由来ポイントを結果へ含める。

### 3. 結果順位の安定ソートを実装する 🔵

**信頼性**: 🔵 *architecture.md 集計方針より*

同点の場合は合計ポイント、最高順位、候補作成順の順に安定ソートする。
