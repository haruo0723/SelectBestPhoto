## タスク概要

年間候補と敗者復活枠から、自分の年間TOP5を下位から順位付きで入力・編集・完了できるようにする。

## 依存タスク

- **前提タスク**: TASK-0020, TASK-0022
- **後続タスク**: TASK-0027, TASK-0028

## 完了条件

- [ ] 年間TOP5を下位から入力できる
- [ ] 年間候補と敗者復活枠を候補に含める
- [ ] 自分の入力を編集できる
- [ ] 相手の入力は編集できない
- [ ] 年間入力状態を保存できる

## 実装詳細

- 🔵 `annualBestInputs/{userId}` に保存する。
- 🔵 年間TOP5は自分と相手がそれぞれ入力する。
- 🟡 候補不足時の表示は実データ状況に合わせて案内する。

## 単体テスト要件

- 🔵 TOP5を超えて選択できない。
- 🔵 下位順位から入力される。
- 🔵 敗者復活枠が候補に含まれる。

## UI/UX要件

- 🔵 月間と同じ操作感で順位入力できる。
- 🔵 年間候補、敗者復活枠の由来が区別できる。
