## タスク概要

Firebase Anonymous Authentication、ペア作成、短期限ペアコード発行、ペア参加、使用後失効を実装する。

## 依存タスク

- **前提タスク**: TASK-0002, TASK-0006, TASK-0007
- **後続タスク**: TASK-0010, TASK-0018, TASK-0027

## 完了条件

- [ ] Anonymous sign-inが実装されている
- [ ] ペア作成時に `pairs` と `pairCodes` が作成される
- [ ] ペアコード参加時にmembersへ追加され、コードが失効する
- [ ] 3人以上の参加を防ぐ
- [ ] 平文ペアコードを永続保存・ログ出力しない

## 実装詳細

- 🔵 明示的なログイン画面は作らない。
- 🔵 ペアコードは短期限かつ使用後失効とする。
- 🟡 ハッシュ方式とコード桁数は安全性とUXを踏まえ実装時に決める。

## 単体テスト要件

- 🔵 未サインイン時に匿名認証が呼ばれることを確認する。
- 🔵 期限切れ、使用済み、存在しないコードで参加できないことを確認する。
- 🟡 Firebase Emulatorでの実接続はTASK-0034で確認する。

## UI/UX要件

- 🔵 エラーは「期限切れ」「使用済み」「コードが見つからない」などユーザー向けに出す。
- 🔵 ペアコードやuidを画面外ログへ出さない。
