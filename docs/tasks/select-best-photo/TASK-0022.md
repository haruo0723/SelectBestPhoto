年ごとの敗者復活枠を1-2件の設定範囲で選択・編集・リセットし、年間TOP5とメディア型カスタム部門の候補に含める。

## 完了条件

- [ ] 全ての写真・動画から敗者復活枠を選べる
- [ ] 年ごとの1-2件設定を反映する
- [ ] 編集とリセットができる
- [ ] リセット時に確認ダイアログを表示する
- [ ] 不要な派生メディア削除候補を更新できる

## 実装詳細

- 🔵 `revivalPicks/{userId}` に保存する。
- 🔵 選択メディアは年間TOP5とメディア型カスタム部門の候補へ含める。
- 🟡 「全ての写真・動画」の取得範囲はmediaAssets参照スコープを使って実装する。
