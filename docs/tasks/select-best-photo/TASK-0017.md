## タスク概要

リセットや編集時に `mediaAssets.referenceScopes` を更新し、参照がなくなった派生ファイルだけをStorageから削除する。

## 依存タスク

- **前提タスク**: TASK-0016
- **後続タスク**: TASK-0022, TASK-0031

## 完了条件

- [ ] 対象スコープの参照を外せる
- [ ] 参照が空のmediaAssetを `pendingDeletion` にできる
- [ ] Storage削除成功後に `deleted` へ更新できる
- [ ] 削除失敗時に再試行可能な状態を残せる

## 実装詳細

- 🔵 削除対象はFirebase Cloud Storage上の派生ファイルに限定する。
- 🔵 端末またはiCloud写真ライブラリ上の元データは削除しない。
- 🟡 トランザクション境界とStorage削除順序は失敗時再試行を優先して調整する。

## 単体テスト要件

- 🔵 複数参照が残るmediaAssetは削除対象にならない。
- 🔵 参照が空のmediaAssetだけpendingDeletionになる。
- 🟡 Storage削除失敗の再試行はモックで検証する。
