## タスク概要

Swift Package ManagerでFirebase Apple SDKを導入し、初期スコープに必要なFirebaseモジュールをXcodeターゲットへ追加する。

## 依存タスク

- **前提タスク**: TASK-0001
- **後続タスク**: TASK-0003, TASK-0005, TASK-0008, TASK-0009

## 完了条件

- [ ] Firebase SDKがSPMで追加されている
- [ ] `FirebaseCore`, `FirebaseAuth`, `FirebaseFirestore`, `FirebaseStorage` が利用可能
- [ ] App Check/Crashlytics/XLSX依存は初期導入していない
- [ ] 依存追加後にビルドできる

## 実装詳細

- 🔵 SPMリポジトリは `https://github.com/firebase/firebase-ios-sdk` を使う。
- 🔵 初期モジュールは設計書で指定された4つに限定する。
- 🟡 Firebase SDKの正確なバージョンは導入時点のXcode/SPM解決に従う。

## テスト要件

- 🔵 Firebaseモジュールをimportする最小ビルドが通る。
- 🟡 Firebaseプロジェクト実接続はTASK-0005以降で扱う。

## 注意事項

- 大きな依存追加はユーザー確認が必要。
- `GoogleService-Info.plist` の扱いはFirebase設定タスクで明示する。
