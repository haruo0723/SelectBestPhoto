## タスク概要

年ごとのメディア型カスタム部門を作成し、年間候補と敗者復活枠からTOP3を下位から順位付きで入力できるようにする。

## 依存タスク

- **前提タスク**: TASK-0020, TASK-0022
- **後続タスク**: TASK-0027, TASK-0028, TASK-0029

## 完了条件

- [ ] 年ごとに複数部門を作成・管理できる
- [ ] 部門ごとにTOP3を入力できる
- [ ] 年間候補と敗者復活枠を候補に含める
- [ ] 自分の入力を編集できる
- [ ] 部門全体リセット確認を表示できる

## 実装詳細

- 🔵 `customCategories/{categoryId}` と `mediaInputs/{userId}` を使う。
- 🔵 メディア型部門は年間ベスト候補からTOP3を選ぶ。
- 🟡 部門一覧の並び順は作成日時を基本にする。

## 単体テスト要件

- 🔵 TOP3制約を確認する。
- 🔵 年間候補+敗者復活枠から候補を作る。
- 🔵 相手入力を編集できない。

## UI/UX要件

- 🔵 部門名と候補メディアが分かりやすい画面にする。
- 🔵 リセット時は対象部門全体であることを示す。
