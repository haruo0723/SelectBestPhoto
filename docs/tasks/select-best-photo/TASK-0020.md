## タスク概要

月間ベストから年間ベスト候補へ進める写真・動画を、年/月ごとの候補件数設定に従って選択する。

## 依存タスク

- **前提タスク**: TASK-0019
- **後続タスク**: TASK-0021, TASK-0022, TASK-0023

## 完了条件

- [ ] 月間ベストから年間候補を選べる
- [ ] 年/月ごとの年間候補件数を反映できる
- [ ] 月間ベスト件数とは別に候補件数を扱える
- [ ] `annualCandidates/{userId}_{month}` に保存できる

## 実装詳細

- 🔵 年間候補件数は年ごと、月ごとに保持する。
- 🔵 月間ベスト件数と年間候補件数は別々に設定できる。
- 🟡 候補選択画面は月間結果から遷移できる構成を基本にする。

## 単体テスト要件

- 🔵 月ごとの候補件数制約を確認する。
- 🔵 候補保存時にuserId/month/mediaAssetIdsが保持される。

## UI/UX要件

- 🔵 候補対象と選択済み件数が分かる。
- 🔵 設定件数超過時は分かりやすく操作を止める。
