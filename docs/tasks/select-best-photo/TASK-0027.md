## タスク概要

月間、年間、カスタム部門、テキスト候補型部門の入力状態を同期し、両者完了前は相手の入力内容を表示しない制御を実装する。

## 依存タスク

- **前提タスク**: TASK-0010, TASK-0019, TASK-0021, TASK-0023, TASK-0024
- **後続タスク**: TASK-0028, TASK-0029, TASK-0034

## 完了条件

- [ ] 未入力、入力中、入力完了を表示できる
- [ ] 片方だけ完了時に相手入力内容を表示しない
- [ ] 相手の入力状態のみを表示できる
- [ ] Rulesとクライアント表示制御が同じ公開条件に沿う

## 実装詳細

- 🔵 公開条件はクライアント表示制御だけでなくFirestore Rulesでも保護する。
- 🔵 個別入力は本人のみ、相手は公開結果経由にする。
- 🟡 状態一覧の集約クエリはFirestore構造に合わせて最小読み取りにする。

## 単体テスト要件

- 🔵 片方完了時に相手入力内容がViewModelに露出しない。
- 🔵 両者完了時に結果発表へ進める状態になる。

## UI/UX要件

- 🔵 相手が未入力/入力中/完了のどれか分かる。
- 🔵 相手の内容を見せない理由を過剰説明せず自然に示す。
