## タスク概要

テキスト候補型カスタム部門の作成、順位別ポイント、入力対象順位、発表対象順位を部門ごとに管理する。

## 依存タスク

- **前提タスク**: TASK-0009
- **後続タスク**: TASK-0025, TASK-0027, TASK-0028

## 完了条件

- [ ] テキスト候補型部門を作成・編集できる
- [ ] `TextCategorySettings` を保存できる
- [ ] 順位別ポイントを設定できる
- [ ] 入力対象順位と発表対象順位を設定できる

## 実装詳細

- 🔵 `CustomCategory.kind == text` と `textSettings` を使う。
- 🔵 部門ごとのポイント設定に従って結果を集計する前提を作る。
- 🟡 ポイント初期値は実装時にUIで自然な最小値を設定する。

## 単体テスト要件

- 🔵 入力対象順位と発表対象順位の保存を確認する。
- 🔵 順位別ポイントがrankごとに保持される。
- 🟡 不正なポイント値の制約はUI要件に合わせて調整する。

## UI/UX要件

- 🔵 順位とポイントの対応が分かる入力UIにする。
- 🔵 長い部門名でもiPhone画面で破綻しない。
