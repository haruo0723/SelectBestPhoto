## タスク概要

Live PhotosをJPEG単体に潰さず、静止画部分とモーション部分を対応付けて保存し、アプリ上でLive Photosとして再生できるようにする。

## 依存タスク

- **前提タスク**: TASK-0012
- **後続タスク**: TASK-0016, TASK-0029, TASK-0036

## 完了条件

- [ ] Live Photosの静止画部分を生成できる
- [ ] モーション部分を生成または取得できる
- [ ] `live-photo-still.jpg` と `live-photo-motion.mov` の対応を保持できる
- [ ] アプリ上でLive Photosとして再生できる

## 実装詳細

- 🔵 Live Photosは通常写真として潰さない。
- 🔵 Photos/PhotosUI/PHLivePhotoView相当を使う。
- 🟡 具体フォーマットと再構成手順は技術検証で確定する。

## 単体テスト要件

- 🔵 MediaAssetの `kind == livePhoto` とモーションパス保持を確認する。
- 🟡 実Live Photos素材を使う再生確認は手動/統合検証で補う。

## 統合テスト要件

- 🔵 実機または対応SimulatorでLive Photos再生を確認する。

## 注意事項

- 失敗時に通常写真へ自動変換する仕様は決めない。読み込めない場合は再選択または再試行へ誘導する。
