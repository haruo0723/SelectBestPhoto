## タスク概要

テキスト候補型部門で、候補名をCSVまたは手入力で追加・編集し、任意で関連画像を1枚添付できるようにする。

## 依存タスク

- **前提タスク**: TASK-0013, TASK-0016, TASK-0024
- **後続タスク**: TASK-0026, TASK-0028, TASK-0029

## 完了条件

- [ ] 候補名を手入力で追加・編集できる
- [ ] CSVから候補名のみを読み込める
- [ ] 1候補につき関連画像を1枚添付できる
- [ ] 関連画像をmediaAssetsで管理できる
- [ ] テキスト候補入力を順位付きで保存できる

## 実装詳細

- 🔵 Excel/CSVから読み込む候補項目は候補名のみとする。
- 🔵 関連画像は `text-candidate-images/{mediaAssetId}/display.jpg` を使う。
- 🟡 CSVの文字コードや区切り文字は一般的なUTF-8/カンマ区切りを初期対象にする。

## 単体テスト要件

- 🔵 CSVの候補名読み込みを確認する。
- 🔵 候補ごとに関連画像が1枚に制限される。
- 🔵 順位付きテキスト入力が保存される。

## UI/UX要件

- 🔵 候補名と関連画像が一覧で確認できる。
- 🔵 読み込みエラー時に再選択または手入力へ誘導する。
