## タスク概要

月間、年間、カスタム部門の公開結果を下位から上位へ順番に表示し、順位が映える結果発表体験を実装する。

## 依存タスク

- **前提タスク**: TASK-0014, TASK-0015, TASK-0023, TASK-0025, TASK-0028
- **後続タスク**: TASK-0030, TASK-0032, TASK-0035

## 完了条件

- [ ] 下位から上位へ順番に表示できる
- [ ] 月間、年間、メディア部門、テキスト部門で共通体験を提供できる
- [ ] 写真、動画、Live Photosを表示・再生できる
- [ ] 1位、2位、3位の差が自然に伝わるUIになっている

## 実装詳細

- 🔵 公開結果は `RevealResult.entries` を使う。
- 🔵 過去結果もリセットなしで再視聴できる構造にする。
- 🟡 具体的なアニメーション、質感、見せ方はシンプルな初期演出から実装する。

## 単体テスト要件

- 🔵 entriesが下位から上位へ並ぶ。
- 🔵 メディア種別ごとの表示コンポーネントが選択される。

## UI/UX要件

- 🔵 写真・動画・ランキングを主役にする。
- 🔵 説明文は必要最小限にする。
- 🔵 Dynamic TypeとVoiceOverに対応する。
