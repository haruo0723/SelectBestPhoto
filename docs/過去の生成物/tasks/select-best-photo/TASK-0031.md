月間、年間、カスタム部門、テキスト候補型部門、敗者復活枠のリセット確認UIと、再入力後に新しい公開結果を生成する世代管理を実装する。

## 完了条件

- [ ] 各リセットで対象範囲を確認ダイアログに表示する
- [ ] リセット後に両者再入力で再度結果発表を見られる
- [ ] 公開結果の世代を区別できる
- [ ] Storage派生ファイル削除処理と連動できる

## 実装詳細

- 🔵 月間リセットは対象月全体、年間リセットは対象年全体として扱う。
- 🔵 部門リセットは対象部門全体として扱う。
- 🟡 generation番号の採番は既存結果から次番号を決める方式を基本にする。

## 単体テスト要件

- 🔵 リセット対象スコープが正しく作られる。
- 🔵 リセット後に入力状態が再入力可能になる。
- 🔵 新しいRevealResult世代が作られる。

## UI/UX要件

- 🔵 誤操作しやすいリセットには確認手段を用意する。
- 🔵 内部エラーをそのまま表示しない。
