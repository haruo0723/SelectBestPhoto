## タスク概要

過去月を含む月間ベストを、設定件数まで下位から順位付きで入力・確認・編集・完了できるフローを実装する。

## 依存タスク

- **前提タスク**: TASK-0012, TASK-0016, TASK-0018
- **後続タスク**: TASK-0020, TASK-0027, TASK-0031

## 完了条件

- [ ] 月間ベストを下位から順番に入力できる
- [ ] 設定件数まで選択できる
- [ ] 入力中に選択済み内容と順位を見返せる
- [ ] 自分の入力を修正できる
- [ ] 入力状態が未入力/入力中/入力完了で保存される

## 実装詳細

- 🔵 `monthlyBestInputs/{userId}` へ本人入力を保存する。
- 🔵 相手の入力は編集できない。
- 🟡 下位から入力するUIの細かな導線は既存設計に沿って最小実装する。

## 単体テスト要件

- 🔵 設定件数超過を防ぐ。
- 🔵 下位順位からの入力順を確認する。
- 🔵 編集時に順位とメディアIDが更新される。

## UI/UX要件

- 🔵 写真・動画・ランキングが主役に見えるUIにする。
- 🔵 ローディング、保存失敗、再試行導線を用意する。
