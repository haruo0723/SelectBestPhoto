## タスク概要

動画をH.264 MP4へ圧縮し、サムネイルを生成し、アプリ内でAVKit/AVFoundationにより再生できる形式にする。

## 依存タスク

- **前提タスク**: TASK-0012
- **後続タスク**: TASK-0016, TASK-0029

## 完了条件

- [ ] 入力動画からMP4を生成できる
- [ ] 動画サムネイルを生成できる
- [ ] duration/fileSizeなどのメタデータを記録できる
- [ ] アプリ内再生可能性を確認できる

## 実装詳細

- 🔵 動画はH.264 MP4優先とする。
- 🔵 元動画は変更・削除しない。
- 🟡 解像度、ビットレート、長さ、サイズ上限は技術検証値として決める。

## 単体テスト要件

- 🔵 圧縮処理成功時にMP4とサムネイルURLが返る。
- 🟡 AVFoundationを使う処理はテスト可能な境界に分割する。
