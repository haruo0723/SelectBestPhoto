## 3. 確認できた事項

- `docs/requirements.md` が要件の正本である。🔵
- 対象はiOS 18以降、iPhoneのみである。🔵
- UIはSwiftUI、バックエンドはFirebaseである。🔵
- 認証はFirebase Anonymous Authentication + ペアコードである。🔵
- Cloud Firestoreで入力状態、順位、設定、公開状態を管理する。🔵
- Firebase Cloud Storageで軽量化済みメディアを保存する。🔵
- 月間ベスト、年間ベスト、カスタム部門、テキスト候補型カスタム部門、敗者復活枠が対象範囲である。🔵
- アルバム一括読み込み、通知、App Store公開、書き出しは初期スコープ外である。🔵
- Xcodeプロジェクトは未作成で、ビルド・テスト・Lintコマンドは未確定である。🔵
