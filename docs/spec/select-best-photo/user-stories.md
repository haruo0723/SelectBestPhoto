# SelectBestPhoto ユーザーストーリー

## 1. 概要

- 要件名: select-best-photo
- 正本: `docs/requirements.md`
- 技術スタック参照: `docs/tech-stack.md`

信頼性レベルは `docs/spec/select-best-photo/requirements.md` と同じ定義を使う。

## 2. ペア利用開始

- 主ユーザーとして、私は明示的なログイン画面なしでアプリを使い始めたい。そうすることで、思い出登録をすぐ始められる。🔵
- ペア作成者として、私は相手に共有できるペアコードを発行したい。そうすることで、2人で同じカップルデータを使える。🔵
- ペア参加者として、私は受け取ったペアコードを入力したい。そうすることで、相手と同じ月間・年間データを共有できる。🔵
- ユーザーとして、私は自分の表示名とアイコンを設定したい。そうすることで、結果発表や入力状態で誰の内容か分かりやすくしたい。🔵

## 3. 月間ベスト

- ユーザーとして、私は今月や過去月のベスト写真・動画を登録したい。そうすることで、月ごとの思い出を整理できる。🔵
- ユーザーとして、私は月ごとに設定された件数まで順位付きで登録したい。そうすることで、その月のベストを柔軟に決められる。🔵
- ユーザーとして、私は下位から順に入力したい。そうすることで、結果発表と同じ期待感の流れで選択できる。🔵
- ユーザーとして、私は入力中に選択済みの写真・動画と順位を見返したい。そうすることで、重複や順位ミスを避けられる。🔵
- ユーザーとして、私は入力後でも自分の月間ベストを編集したい。そうすることで、選び直しや順位変更に対応できる。🔵
- ユーザーとして、私は相手の月間ベストを入力完了まで見たくない。そうすることで、結果発表の楽しみを保てる。🔵
- ユーザーとして、私は月間データを全体リセットしたい。そうすることで、2人で選び直して結果発表を再度楽しめる。🔵

## 4. 結果発表

- ユーザーとして、私は両方の入力完了後にだけ相手の結果を見たい。そうすることで、公平に結果発表を楽しめる。🔵
- ユーザーとして、私は相手の入力内容ではなく入力状態だけを確認したい。そうすることで、待ち時間の状況を把握できる。🔵
- ユーザーとして、私は結果が下位から上位へ順に表示されてほしい。そうすることで、最後に向けて期待感を楽しめる。🔵
- ユーザーとして、私は順位が視覚的に映える結果画面を見たい。そうすることで、月間・年間の思い出を特別感のある体験として振り返れる。🔵
- ユーザーとして、私は過去の結果発表を再視聴したい。そうすることで、リセットせずに思い出を何度も楽しめる。🔵

## 5. 年間ベスト候補と年間TOP5

- ユーザーとして、私は月間ベストから年間ベスト候補へ進める写真・動画を選びたい。そうすることで、年間ベスト選考に残す思い出を整理できる。🔵
- ユーザーとして、私は月ごと、年ごとに年間ベスト候補へ進める件数を設定したい。そうすることで、月ごとの思い出量に合わせて候補数を調整できる。🔵
- ユーザーとして、私は年間ベストTOP5を順位付きで入力したい。そうすることで、その年の代表的な思い出を2人それぞれの視点で選べる。🔵
- ユーザーとして、私は年間ベスト入力中に選択済みの内容を見返したい。そうすることで、順位や選択内容を確認しながら選べる。🔵
- ユーザーとして、私は年間ベストを全体リセットしたい。そうすることで、2人で選び直し、結果発表をもう一度見られる。🔵

## 6. カスタム部門

- ユーザーとして、私は年ごとに複数のカスタム部門を作成したい。そうすることで、その年らしい観点で思い出を振り返れる。🔵
- ユーザーとして、私はメディア型カスタム部門で年間ベスト候補からTOP3を選びたい。そうすることで、食べ物部門やぬいぐるみ部門などを写真・動画で選べる。🔵
- ユーザーとして、私はカスタム部門TOP3を下位から順に入力したい。そうすることで、結果発表と同じ流れで選択できる。🔵
- ユーザーとして、私は自分のカスタム部門入力だけを編集したい。そうすることで、相手の選択を壊さず自分の内容を調整できる。🔵

## 7. テキスト候補型カスタム部門

- ユーザーとして、私は写真・動画以外の候補項目を使う部門を作成したい。そうすることで、エピソード部門や笑った部門を扱える。🔵
- ユーザーとして、私は候補項目を`.xlsx`、`.csv`、手入力で追加したい。そうすることで、候補数が多い部門でも効率よく準備できる。🔵
- ユーザーとして、私は候補項目に関連画像を1枚添付したい。そうすることで、テキスト候補でも思い出を視覚的に補足できる。🔵
- ユーザーとして、私は部門ごとに順位別ポイントを設定したい。そうすることで、部門の性質に合わせて集計できる。🔵
- ユーザーとして、私は入力対象順位と発表対象順位を部門ごとに設定したい。そうすることで、入力の手間と発表内容を調整できる。🔵

## 8. 敗者復活枠

- ユーザーとして、私は年間候補に漏れた写真・動画も含めて敗者復活枠を選びたい。そうすることで、後から見返して重要だった思い出を年間選考に戻せる。🔵
- ユーザーとして、私は敗者復活枠の件数を年ごとに1-2件で設定したい。そうすることで、年ごとの候補数に合わせて調整できる。🔵
- ユーザーとして、私は敗者復活枠で選んだ写真・動画を年間TOP5やメディア部門の候補に含めたい。そうすることで、候補漏れを救済できる。🔵

## 9. メディアとプライバシー

- ユーザーとして、私は写真、動画、Live Photosをアプリ上で表示・再生したい。そうすることで、登録した思い出を自然に見返せる。🔵
- ユーザーとして、私は端末やiCloud写真にある元の写真・動画・Live Photosが変更・削除されないことを期待する。そうすることで、安心してアプリへ登録できる。🔵
- ユーザーとして、私はFirebaseへアップロードされる対象を認識したい。そうすることで、外部送信される写真・動画を自分で把握できる。🔵
